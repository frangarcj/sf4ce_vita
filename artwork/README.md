# Vita shell artwork

These original SVG compositions are the editable sources for `sce_sys`.
They use typography and geometric shapes; no images, textures, screenshots,
logos or fonts were extracted from the Android APK.

Raster assets are indexed PNGs: icon 128×128, background 840×500,
startup 280×158 and optional banner 320×70. The artwork is distributed under
this repository's GPL-3.0 license. Game names remain their owners' trademarks.
